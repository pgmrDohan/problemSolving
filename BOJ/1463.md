# [1463] 1로 만들기

## 1. 문제 분석

- **난이도:** Silver III
- **링크:** [문제 링크](https://www.acmicpc.net/problem/1463)

## 배운 점 (New Knowledge)

- DP 할 때, 햇갈리지 않게 1부터 초깃값 넣자!
- 알고리즘 분류 보고 푸는 습관 줄여야하는데...

## 5. 최종 코드

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main(void) {
  ios::sync_with_stdio(0);
  cin.tie(0);
  cout.tie(0);
  int T = 0;
  cin >> T;
  vector<int> dp(1000002);
  dp[1] = 0;
  dp[2] = 1;
  dp[3] = 1;
  for (int i = 4; i <= T; i++) {
    dp[i] = min(dp[i - 1] + 1, min(dp[i % 3 == 0 ? i / 3 : i - 1] + 1,
                                   dp[i % 2 == 0 ? i / 2 : i - 1] + 1));
  }
  cout << dp[T] << '\n';
  return 0;
}
```
