# [11726] 2×n 타일링

## 2. 코드 설계 (Pseudo Code)

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<vector<int>> result;

void dfs(int sum, vector<int>& path) {
  if (sum == n) {
    result.push_back(path);
    return;
  }

  for (int i = 1; i <= n - sum; i++) {
    path.push_back(i);
    dfs(sum + i, path);
    path.pop_back();
  }
}

vector<vector<int>> getCombinations(int target) {
  n = target;
  result.clear();
  vector<int> path;
  dfs(0, path);
  return result;
}

int main(void) {
  ios::sync_with_stdio(0);
  cin.tie(0);
  cout.tie(0);
  vector<int> dp(1001);
  dp[1] = 1;
  dp[2] = 2;
  int n = 0, calculated = 2;
  cin >> n;
  if (n > calculated) {
    for (int i = 3; i <= n; i++) {
      vector<vector<int>> ans = getCombinations(i);
      for (auto& v : ans) {
        if (v.size() == 1) continue;
        int foo = dp[v[0]];
        for (int k = 1; k < v.size(); k++) {
          foo = (foo * dp[v[k]]) % 10007;
        }
        dp[i] = (dp[i] + foo) % 10007;
      }
    }
    cout << dp[n] % 10007 << '\n';
  } else {
    cout << dp[n] % 10007 << '\n';
  }
  return 0;
}
```

## 3. 트러블 슈팅 (Retrospective)

### 내 코드의 문제점 (실패 이유)

- **Case:** 알고리즘 자체가 틀림.
- **Cause:** 결과 중심으로 너무 복잡하게 생각함.

### 해결 방안 (수정 사항)

- 마지막은 세로, 가로 두개로 끝남.
- 따라서 `dp[i-1] + dp[i-2]`만 하면 됨.

### 배운 점 (New Knowledge)

- DP에서는 마지막 선택을 기준으로 계산 하는 것임. (이전꺼 다 계산 되어 있으니.)
